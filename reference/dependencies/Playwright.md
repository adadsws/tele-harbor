# Playwright

- 版本：1.61.0（PyPI 固定版本）。
- 来源：[Playwright 官方仓库](https://github.com/microsoft/playwright)、[Python 官方文档](https://playwright.dev/python/docs/intro)。
- 许可证：Apache-2.0。
- 使用范围：通过 pip 安装完整库，以 `channel="chrome"` 操作本机可见 Chrome；不复制或修改上游源码。
- 重建：在项目根运行 `download.bat --help`，它会根据 `requirements.txt` 安装固定版本。Chrome 由用户安装。
