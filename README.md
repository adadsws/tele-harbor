# tele-harbor

[简体中文](README.md) · [English](README_EN.md)

在 Windows 上下载 Telegram 群组里的文件和文字，并按聊天结构自动整理。

## 效果预览
```text
旅行分享 [-1000000001]/
└── [From_2026-11-18-m101] 关联组/
    ├── [From_2026-11-18-m101]/
    │   └── 2026-11-18-g7001/
    │       ├── 2026-11-18-m101_1_8001_海边.mp4
    │       └── 2026-11-18-m102_2_8002.jpg
    └── [From_2026-11-18-m110]/
        └── 2026-11-18-g7001后/
            └── 2026-11-18-m110_这张照片拍得真好.txt
```

图例：

| 标记 | 含义 |
| --- | --- |
| `[-1000000001]` | 群组编号。 |
| `关联组` | 把有回复或引用关系的几段消息放在一起。 |
| `From_日期-m101` | 同一发送者的一段连续消息，可以理解为聊天界面中每出现一次发送人头像，就分成一段；以其中最早消息的日期和编号命名。 |
| `g7001` | Telegram 相册编号。 |
| `m101` | 消息编号。 |
| `g7001后` | 该相册之后的独立消息。 |
| `_1_8001` | 附件序号为 1，媒体编号为 8001。 |

## 开始使用

1. 安装 Python 3.11 或更高版本，以及 Google Chrome。
2. 复制一份 [配置示例](config/config.example.json)，保存为 `config/config.local.json`，设置下载位置。
3. 双击 `download.bat`，在打开的 Chrome 中登录 Telegram。
4. 按数字菜单添加群组，选择一个群组或全部群组开始下载。
