# 安装与登录

[简体中文](SETUP.md) · [English](SETUP_EN.md)

1. 安装 Python 3.11 或更高版本，以及 Google Chrome。
2. 复制 [配置示例](../../config/config.example.json)，在同一文件夹保存为 `config.local.json`。已有配置就继续使用，不要覆盖，也不要多出 `.txt` 后缀。
3. 双击 `download.bat`，等待准备完成，在打开的网页中登录 Telegram。
4. 按 [群组管理](GROUPS.md) 添加群组。

首次启动需要联网准备环境。请使用能查看目标群组的账号。

示例下载位置是项目内的 `~outputs-final/downloaded`，也可在配置中修改。
