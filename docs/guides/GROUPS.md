# 群组管理

[简体中文](GROUPS.md) · [English](GROUPS_EN.md)

## 获取群号

1. 打开 [Telegram Web K](https://web.telegram.org/k/)，登录后点开目标群组。
2. 等待消息显示，按 `Ctrl+L` 查看地址，例如 `https://web.telegram.org/k/#-1000000005`。
3. 复制 `#` 后的完整负数，或复制整个数字地址。示例号码是虚构的，请使用自己的群号，保留负号，不改号码前缀。

群名和菜单序号不是群号。已下载过的群，也可从文件夹名的方括号中找到群号。

| 地址不一样 | 怎么办 |
| --- | --- |
| 含 `/a/` 或使用 `t.me` 链接 | 在上面的 Web K 中打开该群，重新查看地址 |
| 群号后还有 `?message=…` | 只复制 `#` 后、`?` 前的负数 |
| 显示 `#@用户名` | 当前程序不支持；可从该群已有下载文件夹中取群号 |

## 添加或移除

- 添加：双击 `download.bat`，选“新增群组”，粘贴群号或 Web K 数字地址，回车保存。已在清单中的群直接选择即可。
- 移除：选“移除群组”，输入该群的菜单序号。已有下载文件会保留。

菜单序号以窗口显示为准。群号正确却打不开时，检查程序打开的 Chrome 是否登录了有权限的账号。
