# Data and file management

[简体中文](DATA.md) · [English](DATA_EN.md)

## Records and files

Think of downloads in three ways:

- Collected information: messages and attachments in the group.
- Download records: what has been processed and what still needs work.
- Downloaded files: videos, pictures and text actually saved.

These describe their purposes; the program also saves supporting files. Finding a message does not mean it was downloaded. A completion record does not prove the file is still there.

## Can I move or add files?

While the program is stopped, you can move completed videos or pictures, or add other files. Keep program records, manifests and unfinished temporary downloads.

Fast mode skips completed items from records, without replacing moved files or cleaning up extras. The other two modes report issues and attempt recovery or archiving only after confirmation; see [Choose modes and review files](MODES_EN.md).

For example, a completed video moved elsewhere stays skipped in Fast mode; the other modes report its original location as missing. This does not cover moving entire directory trees or program records.
