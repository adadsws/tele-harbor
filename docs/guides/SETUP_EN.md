# Install and sign in

[简体中文](SETUP.md) · [English](SETUP_EN.md)

1. Install Python 3.11 or later and Google Chrome.
2. Copy the [example configuration](../../config/config.example.json) as `config.local.json` in the same folder. Keep an existing configuration; check for an unwanted `.txt` suffix.
3. Double-click `download.bat`, wait for setup, then sign in to Telegram in the browser that opens.
4. Follow [Manage groups](GROUPS_EN.md) to add a group.

The first run needs internet access for setup. Use an account that can view your target groups.

The example saves files to `~outputs-final/downloaded` inside the project. You can change this in the configuration.
