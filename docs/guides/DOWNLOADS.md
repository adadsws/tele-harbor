# 下载与续跑

[简体中文](DOWNLOADS.md) · [English](DOWNLOADS_EN.md)

## 开始下载

1. 双击 `download.bat`。
2. 按需 [切换模式](MODES.md)，再选一个群组或“下载全部群组”；检查模式下显示“检查”。
3. 查看窗口中的进度和“保存到”位置。示例位置为 `~outputs-final/downloaded`，实际位置由配置决定。

还没添加群组时，先看 [群组管理](GROUPS.md)。

## 停止和继续

- 处理中按 `Ctrl+C`，等待结束提示后关闭窗口。
- 下次运行，选择原群组，用下载模式继续。
- 主菜单输入 `0` 退出；其他位置按提示返回。

失败原因见窗口和日志。若出现下载失败的 TXT 说明，原附件仍未下载成功。请保留程序记录和下载中的临时文件，详见 [数据与文件管理](DATA.md)。
