# 模式选择与检查

[简体中文](MODES.md) · [English](MODES_EN.md)

在菜单选“切换模式”，再选择群组。默认使用快速模式。

| 模式 | 下载新内容、继续未完成任务 | 检查已有文件是否缺失、多余或损坏 |
| --- | --- | --- |
| 快速模式 | 是 | 否，信任完成记录 |
| 逐文件下载 | 是 | 是 |
| 检查模式 | 否 | 是 |

后两种模式会一起检查配置中的已下载目录和下载中目录。缺失、多余文件一起列出，等选中的群组处理结束后只问一次：

- 输入 `y`：尝试从 Telegram 补回原已下载、现缺失的文件，把多余文件移到可恢复的归档中；不找其他本地副本。
- 回车或输入 `n`：保持问题文件不动。

文件损坏、记录冲突或检查未完成时会报错，不直接覆盖。补齐不保证成功，也不会自动重建整套丢失的目录或记录。文件多时检查较慢，请查看窗口进度。

移动文件前先看 [数据与文件管理](DATA.md)。
