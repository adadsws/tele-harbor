# Download and resume

[简体中文](DOWNLOADS.md) · [English](DOWNLOADS_EN.md)

## Start downloading

1. Double-click `download.bat`.
2. [Choose a mode](MODES_EN.md), then select one group or “下载全部群组” (Download all groups). Check mode displays “检查” (Check).
3. Follow the progress and “保存到” output path. The example uses `~outputs-final/downloaded`; your configuration sets the actual location.

To add your first group, see [Manage groups](GROUPS_EN.md).

## Stop and continue

- Press `Ctrl+C` during a task and wait for the exit message before closing the window.
- Next time, select the same group and use a download mode to continue.
- Enter `0` in the main menu to exit; follow other prompts to go back.

Check the console and logs for failures. A download-failure TXT explanation means the original attachment is still unfinished. Keep program records and temporary downloads; see [Data and file management](DATA_EN.md).
