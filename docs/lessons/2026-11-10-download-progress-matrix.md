# 副本进度矩阵与窗口边界

完整文件、传输提交日志和完成记录是三个独立状态。复测需在独立数据与登录资料副本中分别制造差异，并用真实 BAT 执行；退出 1 只有与预期错误对应、现场保留时才能算正确拒绝。快速模式的信任跳过与实际文件完整性分别记结论。

快速端点仍可使用已建立的批量索引比较记录路径，不必逐文件读盘。错误位置也能匹配消息号，不能仅凭消息号存在就认定完成。修复后按影响范围复测并保留原失败，跨版本证据明确注明范围。

正常 BAT 可见与代理自动调试无可见窗口分开，显示参数独立于校验参数。未登录时退出并说明原因，不自动转为可见窗口；调试结束核对本批进程已关闭。

范围、选择方式与实际结果见 [实测目录](../LIVE_TESTS.md) 和 [本次验收](../finished_plans/2026-11-10-download-progress-matrix.md)。
