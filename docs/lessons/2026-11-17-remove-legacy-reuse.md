# 旧目录退出运行的验证

旧媒体池曾同时承担媒体导入、归档和测试下载路径开关。移除时分别处理这些用途：安全逐文件发布独立保留，归档回归数据管理根，历史样本显式使用原生接口，路径配置和完成记录不再接入旧目录。

登录迁移按整目录文件身份和 SHA-256 核对；测试样本必须来自实际存在的完整文件，缺失候选仅跳过选样，不改业务记录。用户并行操作成品时，保护审计应明确排除获准范围并保留原始前后快照，不能把整批旧失败覆盖为未发生。

本次最终 258 项离线、三项 BAT 参数检查和最终代码双模式实际入口通过。证据和实测边界见 [阶段验收](../finished_plans/2026-11-17-remove-legacy-reuse.md)，历史遗留继续见 [唯一索引](../plans/2026-11-08-remaining-verification.md)。

用户停止修改后，另建批次恢复全部保护范围，33,856 个文件的完整元数据比较直接通过，D00/D01 四组合通过。生产登记位置被人工整理后，不自动修复或回退；可用已验收隔离样本作哈希参照，仍由真实服务器新下载。详见 [独立复测](../finished_plans/2026-11-17-no-legacy-stable-retest.md)。
