# 简化下载流程复盘

## 项目专项

- Web K 同一标签从一个群组的 hash 跳到另一个群组时可能保留旧聊天；先导航 `about:blank` 完整卸载，再打开目标群组，并以实际 hash 和消息气泡核验。
- 页面无普通下载控件的媒体可尝试 Web K 自身下载管理器；应以真实下载事件、落盘大小和哈希确认结果，不能只凭按钮缺失判定内容保护标记。
- Telegram 消息归组需要查看较旧消息的正文边界；单页扫描可在确认下一完整编组后下载上一编组，再恢复旧端位置继续滚动，无需预扫完整历史。
- 扫描记录保存已知媒体 ID 即可支持失败续跑；已有文件通过目录索引核对，无需另写队列状态日志。

## 跨项目通用实践

- 简化用户流程时，同步移除已失效的命令参数、输出、测试依赖与说明，避免仅隐藏界面上的复杂度。
