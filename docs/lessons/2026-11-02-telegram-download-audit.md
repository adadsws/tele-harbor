# Telegram 下载核验复盘

- 用任务开始前归档的扫描记录固定补下范围；扫描到历史最早端后，新增历史附件与原范围分开统计。第三群原范围 225/225 已落盘，但全历史仍有 30 个新发现的缺口。
- 暂存目录按完整编组发布。即使组内已有 78/80 个文件，也保持在 `downloading`；独立核对编组内媒体 ID、记录大小和文件头，不能只看 BAT 的完成行。
- Web K 文件管理器的分片请求可能长期不返回；有界超时让任务继续并保留失败记录。底层直接请求可读取部分原路径超时的文档，但测试读取分片与全文件入库应分别报告。
- 续查旧失败记录时以当前配置和最新逐项状态为准；会话可用、只处理纯文字消息的 BAT 成功运行，不能证明剩余大附件已续传。
- 用户取消剩余验收时，在完成计划中逐项保留“跳过”与未验证证据；不能把跳过改写成测试通过。
