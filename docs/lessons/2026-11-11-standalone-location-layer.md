# 无 group 消息的定位层

- 下载按新到旧推进，单个头像段内可能没有所需的旧侧相册。定位前先取得持久证据或向服务器补查，只有真实空页或已确认的历史最早边界才能命名“首个group前”。批内默认位置计算不能代替旧侧边界证明。
- 前一相册可跨头像段，目录日期仍要与原相册目录一致。应检查跨页相册全部成员，使用最早日期，不能只取最先返回的最新成员日期。
- 改路径时同步扫描结果、原文路径、验收快照和失败说明登记。显式迁移先保存不可变计划，检查所有来源/目标及元数据冲突，再逐文件改名；目录结构改变不代表 failed 可以升级为成功。
- 使用预览→独立服务器关系核对→实际 BAT 迁移→全体受影响文件哈希→实际预检/续跑→完整只读额外检查的链条。本轮 243 个文件的内容校验全部通过；不把有界预览当作下载成功，也不把受控移动中断重跑当作真实断电恢复。
