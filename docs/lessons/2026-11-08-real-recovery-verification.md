# 真实恢复实测复盘

## 项目专项

- 快速端点落在头像段内部时，带回较新侧完整连续段后缀；只回带最近相册块会让已跳过成员从重写清单中消失。
- 写入段内清单前检查成员集合缩小，拒绝覆盖并保留旧清单；成品审计同时检查已配置群组缺失、旧媒体覆盖及段内集合。
- 真实缺文件测试保存原件、移出活动和复用索引，再让实际 BAT 下载；字节哈希与清单集合共同验收。

## 跨项目通用实践

- 恢复测试记录实际中断点和中断后持久状态，再验证非零偏移重跑及最终哈希。
- 观察正在写入的日志使用允许写入方继续工作的共享只读句柄；监视器自身失败单列，不能记为被测程序或中断测试成功。
- 真实进程中断续传与网络断开自动重连是不同验收场景，分别记录证据和边界。
