# 逐文件核验不能掩盖已有异常

- 已有结果与新资源分开：先只读核对已登记文件与编组，再进入复用、清单写入和下载。已有文件缺失或路径错误时停止；不能以“自动修复”把问题变成成功。
- 精确哈希对比不能只看路径相同；同一媒体文件被改名后，旧可信哈希仍是基线。损坏或缺失的验收记录也不能在严格核验时悄悄重新建立。
- 核验失败保留既有成功记录，避免将它改成失败状态后，下一轮预检漏查。真实测试必须保留原件、注入错误、检查没有修复动作，再恢复并验证正常运行。
- 观察器应按完成汇总行统计，不能数全日志的“失败 0”（进度行也有）；服务器出现真实新资源时，不能把“新下载必须为 0”的过期断言当作产品故障。
