# 进度故障必须覆盖关联成员

相册内断点故障测试通过，不能证明引用关联分量中的异常同样保持现场。此次真实无 group 样本发现：坏断点检查过晚，会先回退同分量的完好成员。验收应分别检查字节、路径和记录变化，保留首次失败；不能把“字节没变”替代“异常前不移动”。

只读预检应复用正式续传的身份、分片和尾部验证逻辑，通过显式只读参数阻止修复或提交；避免另写一套较弱校验。有效断点仍由原续传路径完成提交，远端错误保持原有通用处理。

受控历史起点适合复现小体积真实样本，但不得伪造服务器空页或最早端证明，也不能作为自然外部新增的验收。范围和结果见 [实测目录](../AGENT_CONTEXT.md#实测场景与执行) 及 [阶段记录](../finished_plans/2026-11-12-progress-live.md)。
