# 独立发布与源历史门禁

本项目源仓库没有 remote，且保留待处置历史隐私；公开远端 `adadsws/tele-harbor` 的 `main` 使用独立历史。后续发布应从该公开分支创建隔离副本，只同步经审计的活动源码、测试、配置模板和文档，保留其历史，不关联源 `.git`。

本次在空群组配置下通过 254 项离线测试，并分别验证文件一致性、完整公开历史和远端 refs。公开发布与源仓库提交、历史清除是不同状态，统一由 [遗留索引](../plans/2026-11-08-remaining-verification.md) 记录；验收证据见 [发布记录](../finished_plans/2026-11-17-publication.md)。
