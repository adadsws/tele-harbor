## 2026-11-09

- 明确区分服务器文件错误和连接超时：5xx 使用有界重试，保留失败记录与分片并继续其他文件，不因网页内部自动重试卡住整群；有失败时退出码仍为 1。

- BAT 明确显示正常结束、任务未完成、参数错误与用户中断，保留原始退出码。
- 诊断日志补齐运行开始和结束状态；帮助或参数错误不再留下无法区分原因的空日志。
- 连接恢复仍失败时直接显示中断原因和断点保留提示，不修改有限重试或本地数据保护逻辑。
- 会话入口识别兼容已打开的消息和侧栏结构变化；页面加载、群组导航超时单独提示，不把空页面直接判为未登录。
- 逐文件发布头像段后立即归档空来源目录，避免后续扫描失败导致整轮收尾未执行而留下空目录；逐文件检查仍只读报错，不自动清理。
- 接管分片超时后浏览器调用的迟到终态，关闭页面时回收异常，迟到字节不提交到断点。
