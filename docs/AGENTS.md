# 项目代理规则

适用范围：项目根目录及所有子目录。全局 `AGENTS.md` 仍适用；本文件只记录 telegg 的专项约束。

## 运行与数据

- `download.bat` 是交给用户的 Windows 入口。修改启动或下载流程后，先运行离线测试，再以该入口做有界试运行；未登录或网络不可用时明确记录未验证项。
- 真实 Telegram 会话、扫描记录、分片和下载文件由 `config/config.local.json` 指向本机数据目录。核验路径前先读配置，不能把历史文档里的 `X:\TelegramData` 当作当前真实位置。
- `config/config.local.json` 与群组清单归档只留本机，公开配置结构见 `config/config.example.json`；测试使用临时虚构群组，不读取本机清单。
- 对真实群组使用 `--limit` 或 `--audit-messages` 限制样本；只扫描不能当作下载成功的证据。完整历史仅在服务器返回空页且记录边界满足要求时视为确认。
- 配置示例和测试产物使用约定的输出、中间产物与临时目录，不在根目录创建 `downloads/`、`unused` 或其暂存变体。整理项目时不得改动现有本机配置指向的数据。
- 媒体文件进入成品目录前，核对已提交分片、文件大小和 SHA-256；未齐编组留在暂存目录。已有文件不得覆盖。
- 独立浏览器核对只返回消息 ID、日期、附件类型与 DOM 分组结构；不查看隐私正文、链接内容或图片。程序按需求保存原文文件，不代表代理可以查看其内容。
- 用户正常双击 BAT 保持可见窗口。代理自动调试与实测默认使用 `--debug-window hidden`，不打开可见终端或 Chrome，不抢占焦点；只有明确选择 `visible` 才进行有可见窗口调试。窗口显示与 fast/exact 校验模式相互独立。这是用户明确要求，优先于浏览器 Skill 的默认可见窗口约束。

## 验收与记录

- 项目规范和评测集见 [项目上下文](AGENT_CONTEXT.md)。修改功能时同步更新适用样例，并记录实际输入、过程证据、结果和未验证项。
- 交付前按 [交付优先实测](AGENT_CONTEXT.md#交付优先实测) 核对五项优先验收及证据有效性，关联实测目录中的其他适用项；不能仅凭单元测试、完成标记或旧版本记录宣布全部通过。
- 独立网页观察优先使用 `tests/run_priority_checks.py` 的隔离 profile；跨群初始化先卸载旧页面，确认目标群气泡后再定位，同目标最多重试一次。DOM 时间仅诊断，原始日期以独立服务器元数据核对；服务消息不计普通消息遗漏。观察异常须保留失败状态，不能用旧气泡或地址替代成功证据。
- 用户指定浏览器插件核对时，只返回白名单消息元数据，避免自动输出全页 AX 或截图。慢调试调用单步执行并给足工具时限；本项目已出现约 43 秒才返回的调用，先用 60 秒时限确认，再判断是否断连，不能把默认 30 秒会话重置全部归因于用户未连接。
- 面向用户的行为变化同步更新 [中文说明](../README.md)、[英文说明](../README_EN.md) 与 [变更记录](CHANGELOG.md)。
- 活动任务计划放在 `docs/plans/`；确实完成后再移至 `docs/finished_plans/`，并在 `docs/lessons/` 记录精简复盘。
- 当前遗留以 [遗留索引](plans/2026-11-08-remaining-verification.md) 为唯一状态入口；已结束阶段的验收摘要保留在完成记录中，明确移交尚未完成的任务，不把阶段关闭写成原件恢复或全部验收完成。文档职责及证据索引见 [文档导航](README.md)。
- 用户停止某原件专项恢复后，后续诊断选样先检查本机 `live-test-exclusions.json`；遵守实测排除，不再重复读取该原件字节。此限制不扩大为正式程序永久屏蔽，生产通用报错、同名 TXT 及继续处理机制保持不变。
