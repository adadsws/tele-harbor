# 下载进度与双模式隔离实测

按 [当前规范](../AGENT_CONTEXT.md) 验收，使用真实 BAT、无可见窗口 Chrome 和已下载文件的独立副本。不修改原下载、暂存、断点、扫描记录、配置或浏览器资料；原数据目录不作为测试输出。正常用户双击 BAT 仍可见；调试窗口 hidden/visible 独立于 fast/exact，本轮自动调试固定 hidden。

- [x] 已提交断点、数据领先记录、记录领先数据、孤立分片、孤立日志、身份变化、已提交损坏、未提交尾部冲突、日志撕裂、完整分片未入库，交叉两模式。
- [x] 成品缺失、同大小损坏、截断、错误路径，验证逐文件模式只读报错及快速模式能力边界，并实测切换模式。
- [x] 新下载/续传独立校验大小与 SHA-256，失败不误记完成；记录耗时、可信起点、退出码与原文件保护结果。
- [x] 发现不符合要求的行为先修复，离线回归后用真实入口复测；完成后记录可复用选择方式与结果。

本轮模拟源状态只改变隔离副本。全新下载仍从 Telegram 取得资源，不能将本地拷贝伪称网络下载。快速模式不逐字节检验已完成文件，隐性损坏须通过逐文件模式发现；“符合快速模式预期”不代表损坏副本通过完整性校验。

历史未完成和未验证事项继续见 [遗留清单](../plans/2026-11-08-remaining-verification.md)，旧原件的服务器错误不属于本轮正常网络样本。

真实矩阵发现 L03/fast 错误路径被误报完成，exact 正确拒绝。修复快速端点的索引路径一致性判断，不增加逐文件 I/O；离线回归后复测 D01、L00、L03 与 R01，原失败结果保留，不能作为通过依据。

## 实际结果

| 范围 | 输入、过程与结果 |
| --- | --- |
| 离线回归 | 隔离配置和测试目录，无可见窗口运行 152 项，全部通过；路径比较测试明确禁止逐文件 stat |
| 真实进度矩阵 | 一个已下载小相册的 10 个文件，共约 50.1 MiB；普通场景分别 fast/exact，三条连续模式切换，共 42 种组合 |
| 失败与修复 | 首轮 41/42 符合预期；修复 L03 后相关 12 项真实复测全部通过，合并最新有效证据后 42/42 符合预期。证据跨两个版本，未宣称修复后重新跑过所有场景 |
| 路径错误 | fast 将副本移回规范位置，10 个文件哈希全部匹配；exact 非零退出、保留现场 |
| 预期拒绝 | 18 个拒绝组合均另查具体断点错误或本地数据错误，排除把无关网络/登录失败当作预期拒绝 |
| 空目录与退出 | 成功场景业务空目录为 0；42 项均有正常 RUN_EXIT；刻意构造的损坏副本不算完整性通过 |
| 原件保护 | 全部原数据文件的大小、修改时间和文件身份未变；10 个样本、配置、源扫描记录的 SHA-256 未变。未声称逐字节复读所有原数据 |
| 窗口与未登录 | 所有本轮自动下载实测使用 hidden。空登录资料的真实 BAT 在约 31.8 秒明确提示登录未就绪、退出 1，未自动转可见模式；退出后没有遗留本批浏览器/下载进程 |
| 时间差 | 同一完整样本 fast 的 BAT 总耗时 5.52 秒、群处理 3.0 秒；exact 为 6.27 秒、3.7 秒；单次差约 0.75 秒、0.7 秒，含启动及网络波动，不能外推大数据加速比例 |

可选范围和证据文件约定见 [实测目录](../LIVE_TESTS.md)。本机批次的 `acceptance-summary.json` 保留合并判定与具体错误复核，`hidden-no-login-result.json` 记录未登录结果，私有原始日志不公开。

## 范围限制

正常 BAT 的默认可见行为由参数与启动调用回归确认；本轮按用户要求没有再次打开可见窗口做界面体验。目录中其余需单独执行的 17 类不因本矩阵通过而自动算完成，历史证据及未验证子项仍分别有效。实际断网、外部自然新增相册、历史慢跑复现及三群全量历史均不在本轮模拟矩阵的通过范围。
