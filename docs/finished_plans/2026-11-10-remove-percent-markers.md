# 取消项目命名中的百分号标记

历史阶段记录：数字、版本和未验证条件仅代表记录时点；当前任务状态见 [遗留索引](../plans/2026-11-08-remaining-verification.md)，命名与交付要求见 [现行规范](../AGENT_CONTEXT.md)。

## 范围

项目新生成的辅助文件与目录不再使用百分号前缀。原始媒体文件名、正文及进度百分比保留。旧异常登记只读兼容，正常写入或显式迁移时逐文件改名；冲突、损坏须报错，不覆盖文件，不移动目录。

## 实施与验收

- [x] 更新命名规范、异常登记及临时文件命名，沿用已有所有权/哈希与只读预检机制。
- [x] 离线验证新命名、旧登记索引排除、只读预检、写入/恢复迁移、损坏和同名冲突保护。
- [x] 实际 BAT 以隔离副本验证 fast 失败说明及 exact 联网恢复，核对归档和无百分号前缀。
- [x] 核对活动数据，逐文件迁移已确认属于脚本的旧登记，验证媒体、配置、记录及断点不变。
- [x] 文档和隐私检查后本地提交，不操作远端。

## 验收证据

- 隔离离线套件 170 项通过；新增旧登记只读识别、写入改名、恢复归档、新旧冲突、修改过的说明及空登记保护样例。
- 实际 BAT：fast 注入文件错误，21.32 秒以预期失败退出，自动生成的新登记不带百分号；在副本中改成旧登记后运行 exact，16.31 秒真实联网恢复，10 个文件独立 SHA-256 全部匹配，说明及登记按新名称归档。
- 真实错误与注入错误分别记录；本次没有以注入错误验证服务端 500 的恢复。
- 活动数据盘点：成品、暂存、断点、扫描记录只有一份旧登记，未发现其他带标记路径。迁移前后逐文件只读预检通过，唯一变化为该登记改名；登记内容、媒体索引、快速端点、配置、扫描记录和断点哈希不变，原失败状态保持。
- 活动数据迁移后上述四类业务根无百分号前缀路径。历史归档及旧测试批次保留原始证据，旧格式只读兼容，不批量改写原始媒体或旧记录。
- 私有保护快照留本机 `~temp/no-percent-markers/`，BAT 隔离结果留 `~temp/remaining-live/` 本轮副本；正式代码和文档不含原始文件名、群号或登录资料。

## 原有遗留

旧 500 原件恢复、隐私备份处理、自然新增端点及历史慢跑原条件等继续见 [遗留清单](../plans/2026-11-08-remaining-verification.md)，不因命名更新视为通过。
