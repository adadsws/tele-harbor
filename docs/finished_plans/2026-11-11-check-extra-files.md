# 额外文件只读检查

历史阶段记录：以下行为、数量和结论对应当时版本与样本；不作为当前模式说明或本次重新实测的结果。当前规则见 [项目规范](../AGENT_CONTEXT.md)，当前状态见 [遗留索引](../plans/2026-11-08-remaining-verification.md)。

遵循 [项目规范](../AGENT_CONTEXT.md)，本任务只增加路径报告，不扩大为文件清理或下载修复。

## 需求与边界

- 保持现有文件不动；在 `download.bat` 的菜单增加独立检查模式，支持命令行直接调用。
- 只报告额外文件的绝对路径，不下载、移动、删除、修复文件，不写扫描记录、完成状态或断点。
- 按用户后续明确范围，覆盖 `downloaded` 与整个 `downloading`，包括 `groups`、`partials` 和根层散落文件；用户明确排除旧媒体复用目录，归档和会话也不扫描。
- 按本地文件涉及的消息范围向服务器分页，只获取消息/媒体身份及文字是否存在等白名单元数据。只有分页成功覆盖该范围后才判断本地无对应远端附件；网络、权限或响应异常必须保留检查失败，不能当作群里已删除。
- 区分普通重复媒体、合法编号版本、消息原文、辅助清单和已登记失败说明；既有历史版本保留。无法识别的额外文件也只指出路径。

## 实施与复用

复用现有 Chrome 会话、群组入口、窗口选择、版本编号识别及异常说明只读登记。独立模块补充文件盘点、白名单服务器分页和只读比对，不进入 `download_group` 或清单整理流程。菜单在原位置增加第三种模式；正常 BAT 窗口保持可见，代理实测显式 hidden。
